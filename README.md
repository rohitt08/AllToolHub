# AllToolHub

A fast, modern online calculator suite with 100+ calculators for finance, fitness, math, and everyday utilities. Built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features

- **100+ Calculators**: Financial (mortgage, loans, investments), fitness (BMI, calories, body fat), math (scientific, percentage, statistics), and daily utilities.
- **Instant Client-Side Math**: Real-time calculations with zero server latency.
- **Clean UI**: Modern, responsive interface with instant fuzzy search (`Ctrl+K`).
- **SEO Optimized**: Built-in JSON-LD structured data, FAQ rich snippets, and complete XML sitemaps.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
